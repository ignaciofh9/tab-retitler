Tab Retitler

Rename tabs and badge their icons using rules based on each page’s URL and content. Teach it by example in Chrome’s side panel.

Type the title you want for a tab and Tab Retitler works out where each part comes from: the address, the page title, or text on the page. Give it examples from a few tabs and it narrows down to the rule that fits them all. Icons can follow the page too, like a green dot when a task is done.

Everything stays on your computer. There's no account, no analytics, and it only runs on sites you allow.
